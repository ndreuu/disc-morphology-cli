# Проверка версии 0.1.0

22 ноября 2026 года.

## Установка и независимость

Пакет собран и установлен в собственное Python 3.12 окружение с NumPy 2.5.5, pydicom 3.0.2 и Pillow 13.0.0. Проверены настоящая console-команда `disc-morphology`, `--help`, `--version`, `inspect`, `demo`, `analyze`, `verify` и отсутствие сломанных зависимостей через `pip check`. Импортов старого MRI-репозитория и зашитых путей этой машины в исполняемом коде нет.

44 автоматических теста проходят локально. В CI проходят Python 3.10 и 3.12: установка wheel, тесты, синтаксис JavaScript и генерация автономного demo-отчёта. Тесты содержат только синтетические DICOM/маски.

## Полный реальный запуск

Установленная CLI-команда реально обработала контрольное публичное RSNA-исследование: 15 сагиттальных T2 и 30 аксиальных T2 кадров. Серии автоматически выбраны по DICOM. Для этого анонимизированного набора явно использованы `--allow-missing-modality` и исследовательский `--allow-unverified-registration`.

Выполнен полный TotalSpineSeg → SpineSegPlus Stage A/B, без подстановки сохранённых масок. Четыре официальных архива сверены по SHA; производные checkpoint прошли проверку равенства каждого тензора. Модельный runtime — существующий изолированный Python 3.12 / torch 2.5.1 / NumPy 2.2.6. На CPU с ограничением до двух потоков модельная стадия заняла 381,879 с, полный запуск — 384,151 с. Получены `report.html`, `result.json`, `run.json`, исходный NIfTI, фактические маски, журнал и подписанный SHA-фактами маркер завершения.

Преобразование сохраняет аудированный порядок `rows, columns, slices`, с сортировкой вдоль DICOM-нормали. При повторном чтении NIfTI **каждый native-пиксель всех сагиттальных кадров** проверяется через физические координаты. Дополнительно независимый SimpleITK подтвердил полное совпадение входного массива, origin, spacing и direction с прежним аудированным преобразованием.

Свежая маска содержит 203 вокселя на автоматически предложенном L3–L4. Клинический результат — `indeterminate`. На части кадров пригодное основание отсутствует, на кадре с численными оценками маска несвязная и пересечение опорной линии неоднозначно. Интерфейс показывает доступные B/D/H/R отдельно от отказа классифицировать форму. Для остальных уровней отсутствие маски не превращается в диагноз отсутствия грыжи.

Свежий контур отличается от прежнего сохранённого результата в 147 вокселей. Причина расхождения отдельно не установлена; устойчивость сегментации и клиническая точность этим запуском не подтверждены. Повторный показ прежней маски через явный `--candidate/--anatomy` воспроизвёл B≈8,296, D≈13,481, H≈5,786 мм и D/B≈1,625. Этот дополнительный пример помечен как использование внешней сохранённой маски, без нового inference.

`verify` успешно сверил 50 файлов исходников, масок и результата полного запуска. Он проверяет целостность относительно локального manifest, не клиническую правильность.

## Браузер

Проверены реальные изображения, видимый исходный контур, подписи B/D/H, ползунки обеих плоскостей и обновление чисел выбранного среза. Срез без основания показывает неопределённые размеры; перенесённая аксиальная маска не подтверждает тип. В demo проверены обе гипотезы, подстановка D/B и изменение чисел при перемещении ползунка. Отчёт не загружает скрипты, стили, шрифты или изображения из сети.

Рабочие DICOM, веса, реальные отчёты и локальные журналы остались вне Git. В репозиторий включён только явно синтетический HTML-пример.
